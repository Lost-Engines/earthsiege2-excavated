# Earthsiege 2 Excavated

An illustrated look inside Dynamix's Earthsiege 2: animated HERC models, compiled mission scenery, cockpit artwork, original software rendering and the discoveries behind a C++ reconstruction.

[Visit the site](https://lost-engines.github.io/earthsiege2-excavated/) · [Read the investigation](https://lost-engines.github.io/earthsiege2-excavated/story/)

Part of the [Lost Engines Project](https://lostengines.com/), following [Earthsiege Exhumed](https://lost-engines.github.io/earthsiege-exhumed/), [Darker Discovered](https://lost-engines.github.io/darker-discovered/) and [TFX Traced](https://lost-engines.github.io/tfx-traced/).

The committed display snapshot builds independently of the analysis workspace:

```sh
npm ci
npm run build
npm run check
npm run preview
```

Open `http://127.0.0.1:4182/`. See [MAINTAINING.md](MAINTAINING.md) for imports, screenshot capture, browser checks and deployment; [RIGHTS.md](RIGHTS.md) covers original content and attribution.
